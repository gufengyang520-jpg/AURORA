# AURORA 1.0.0 重构计划

> 目标：把现在"能用但丑"的 2.0.1 做成一个对外发布级的 1.0.0。
> 版本号按你要求重置为 **1.0.0**（versionCode 1），后续从 1.0.x 正常递增。

## 一、先看清参考对象

KernelSU 管理器的技术栈（从仓库里读出来的，不是印象）：

| 项 | 内容 |
| --- | --- |
| UI | Jetpack **Compose** + Material3（1.5.0-alpha28，用了 expressive API） |
| 风格库 | **MIUIX Compose**：`top.yukonga.miuix.kmp:miuix-ui / miuix-icons / miuix-nav / miuix-preference / miuix-blur` 0.9.4 |
| 模糊 | 独立依赖 `miuix-blur` |
| 预测性返回 | `androidx.navigationevent:navigationevent-compose` |
| 网络 | OkHttp 5.5 + kotlinx-serialization |
| 构建 | Gradle + AGP 9.4.1 + Kotlin 2.4.20，minSdk 26、targetSdk 36 |

也就是说：**KSU 那套观感 = Compose + MIUIX + miuix-blur**，不是原生 View 能做出来的。这直接决定我们的路线。

## 二、技术路线（需要你拍板）

### 路线 A：Compose + MIUIX（对齐 KSU）

- 拿到：真正的 MIUIX 组件、`miuix-blur` 的真实背景模糊、组件自带动效、预测性返回
- 代价：构建体系要从现在的 `javac + d8 + aapt` 换成 **Gradle**；首次要联网拉 ~600MB–1GB 依赖；可能要把 SDK 升到 36（现在只有 android-35 / build-tools 35）
- 风险：`miuix` 只发布在 JitPack 一类仓库，版本与新 Compose 有耦合，可能出现解析失败或版本冲突

### 路线 B：自建设计系统（沿用现在的构建链）

- 拿到：10 秒构建、零依赖风险、完全可控
- 只能"仿"：模糊用 RenderEffect 做局部毛玻璃，动效用 ViewPropertyAnimator，预测性返回用 `OnBackInvokedCallback`
- 观感上限明显低于 MIUIX，但做得克制也可以很干净

**我的建议**：先做 **M0 技术验证**（30 分钟）——只验证一件事：能不能拉到 miuix 依赖并跑起一个空 Compose 页面。
- 验证通过 → 走 A，观感一步到位
- 验证失败 → 自动降级 B，不浪费你时间

M0 不写业务代码，只出结论，我不会先斩后奏。

## 三、信息架构

四个页面，每页一个任务：

| 页面 | 任务 | 内容 |
| --- | --- | --- |
| **音效** | 选一个风格立刻听 | 大卡片横向切换预设（哈曼卡顿/柏林之声/…）、总开关、当前曲线缩略 |
| **均衡** | 自己调 | 6 段可拖曲线、强度、恢复平直（带确认） |
| **诊断** | 确认是否真生效 | 测试音自检、系统回执、会话列表 |
| **设置** | 应用级操作 | 外观（模糊底栏/液态玻璃/角标/导航栏）、**检查更新**、关于 |

保留全局：**每页顶部固定一条实时状态条**（你要的第 4 点）。

## 四、实时状态条（每页都有）

一个 40dp 高的细条，压在标题下方，四个页面都在，2 秒刷新：

```
● 正在生效   会话 305 · 哈曼卡顿 · 70%
○ 等待播放   没有音频在播，参数不会写入
● 已关闭     音频走原厂链路
▲ 写入失败   点击查看原因并重试
```

状态点用颜色 + 文字双重表达（不只靠颜色）。点状态条可进入对应详情（失败→诊断页）。

## 五、视觉与动效

**设计令牌**
- 主色：单一强调色（浅色 `#2F5BD0` / 深色 `#8FB4FF`）
- 中性色：6 档灰阶承担全部其余元素
- 圆角：卡片 20dp、控件 12dp、悬浮底栏 28dp
- 间距：8pt 网格；正文 15sp、标题 28sp
- 字体：系统字体（MIUIX 本身就是系统字重体系）

**要做的四件事（对应你说的 a/b/d/e）**
1. **模糊悬浮底栏**：底部胶囊悬浮、与内容留出间距、背景真实模糊，滚动时内容从底下穿过
2. **液态玻璃**：卡片/底栏用半透明 + 高光描边 + 背景模糊；**设置里可关闭**（低端机/掉帧时用）
3. **角标**：状态点角标（生效/等待/关闭/失败）+ 会话数量角标
4. **预测性返回**：页面切换时跟随系统返回手势的位移预览（Android 14+ 才启用，低版本自动退化为普通返回）
5. **导航栏**：设置里可切"悬浮胶囊 / 贴底通栏"两种形态

**动效**
- 页面切换 200ms 淡入+8dp 位移
- 预设卡片横向滑动吸附，切换时曲线图做插值过渡
- 开关、滑杆用 MIUIX 风格的回弹
- 全部动效在"省电/低性能"模式下可一键关闭

## 六、预设重做（重点）

现状问题：几套预设差异不够，因为之前只在 250Hz–6.3kHz 里做 ±2–4dB 的微调。

重做原则：**每套至少有一个频段相对"原厂平直"偏移 ≥5dB，两两之间至少一档差 ≥5dB**，并给一句听感说明。

| 预设 | 250 | 500 | 1k | 2k | 4k | 6.3k | 一句话 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 原厂平直 | 0 | 0 | 0 | 0 | 0 | 0 | 不叠加 |
| 自然均衡 | +1 | +1 | 0 | 0 | +1 | +1 | 几乎不动，只补一点厚度 |
| **哈曼卡顿** | +6 | +5 | 0 | -1 | -2 | -3 | 低频有量、高频柔顺，久听不累 |
| **柏林之声** | 0 | -1 | +1 | +3 | +5 | +5 | 中高频打开，器乐分离度好 |
| 现场低频 | +7 | +6 | +2 | -2 | -3 | -3 | 鼓点最实，中高频让位 |
| 影院包围 | +5 | +4 | +1 | -1 | -2 | -3 | 下盘厚、声场偏宽 |
| 人声清晰 | -4 | -3 | +3 | +6 | +3 | 0 | 主唱贴耳，背景退后 |
| 明亮解析 | -2 | -2 | 0 | +3 | +6 | +6 | 齿音和镲片更清楚 |
| 夜间柔化 | +3 | +2 | 0 | -4 | -6 | -6 | 小音量不刺耳 |

数值我会在真机上按听感再校一轮（每套都要你确认"能明显听出差别"再定稿）。

## 七、检查更新

- 数据源：**GitHub Releases**（`/repos/{owner}/{repo}/releases/latest`），只读、不需要后端
- 展示：当前版本 / 最新版本 / 更新日志 / 「前往下载」
- 比较：语义化版本；本地 `BuildConfig.VERSION_NAME`
- 容错：无网、超时、404、字段缺失 → 分别给明确文案 + 重试，绝不白屏或假装"已是最新"
- 频率：手动点击为主，启动时静默检查一次（可关）

**需要你定**：GitHub 仓库地址（owner/repo）。没有的话我可以先建一个占位常量，后面改一行就能用。

社区功能按你说的先不做。

## 十、风险与对策

| 风险 | 对策 |
| --- | --- |
| miuix 依赖拉不到 / 版本冲突 | M0 暴露，直接降级路线 B |
| AGP 9.x 需要 SDK 36，我们只有 35 | 用 sdkmanager 装 36；或锁 AGP 8.x + 对应 Compose |
| 模糊在老 ROM 掉帧 | 设置里可关玻璃效果，默认按设备能力开 |
| Compose 与 LSPosed 模块共存 | 模块入口仍是 Java 类（`AuroraXposed`），只换 UI 层 |
| 改动 UI 影响已验证的音频链路 | 音频引擎（AudioEq/AuroraEngine）本轮**不改**，只在 UI 层动 |
