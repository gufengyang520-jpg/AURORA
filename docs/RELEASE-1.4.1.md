# AURORA 1.4.1

1.4.1 修两个声音上的问题，都在「换歌 / 换应用的那一瞬间」：一是切应用时的一声爆响，二是低频一直被压着喘气、听感发闷。设置项、格式、键名一字未改。

## 1. 切应用不再有爆响

旧代码在写曲线前有一段淡入，但它只对「已经写入过」的处理链生效。注释里给出的理由是：新打开的链从平直开始，而「曲目还没开始」，所以从平直滑上去的四次写入等于白写。

这个假设只在 AURORA 先于播放打开会话时成立。**从抖音切到别的应用时，会话已经在放音了**，新的处理链接手的是半句话中间的一个信号：

1. 第一帧直接把整条曲线写进去；
2. 同一帧里 setEnabled(true) 把效果器一次性上电。

两件事在同一帧发生，听起来就是一下爆响。1.4.1 把这两条路分开：

- **已经写入过的链**：仍在 4 帧内（每帧 40 ms）从当前曲线滑到新曲线，行为不变；
- **刚打开的链**（或上一帧写入失败、已经忘掉自己写了什么的链）：从**全平直**起步，6 帧、每帧 20 ms，最后一帧落到目标曲线。第 0 帧是刻意的一帧平直——它就是「把效果器打开」的那一帧，让链先跑起来，再要第一个 dB。

每帧都是真实写入，DSP 用新系数重新锁存，而不是在它从没见过的信号下被突然开机。任意一帧被链拒绝，整次写入判失败并交给上层处理，不会把曲线停在半坡上。

自检（全频段 -12 dB）不走淡入，它是故意的瞬时静音，用来听链在不在。

## 2. 低频压缩：从「一段」到「六段」，并且单位是毫秒

旧代码只写 MBC（多段动态压缩）的第 0 段，其余五段留在平台默认。而 AOSP 的默认是 ratio = 1，也就是**不压缩**——所以实际效果是「只有 120 Hz 以下一段在压，上面全是直通」，不是设计意图里的「轻压缩」。

更麻烦的是时间常数：MbcBand 的 attack / release 单位是**毫秒**，旧代码写的是 0.020f 与 0.250f——0.02 ms 的 attack、0.25 ms 的 release。那不是压缩器，是装在低音上的波形整形器：每次低频一来就被瞬间按住、又瞬间松开，听感就是低频发紧、随鼓点抽动，也是「闷」的一部分来源。

1.4.1 把六段整表写出（每段独立 try/catch，写成功几段就报几段）：

| 段 | 上边界 | 比例 | 阈值 | attack | release |
|---|---|---|---|---|---|
| 0 | 120 Hz | 2:1 | -24 dB | 20 ms | 250 ms |
| 1 | 350 Hz | 1.4:1 | -30 dB | 25 ms | 300 ms |
| 2 | 900 Hz | 1:1 | — | 3 ms | 80 ms |
| 3 | 2.5 kHz | 1:1 | — | 3 ms | 80 ms |
| 4 | 6.5 kHz | 1:1 | — | 3 ms | 80 ms |
| 5 | 16 kHz | 1:1 | — | 3 ms | 80 ms |

只压低频两段，中高频全直通——手机扬声器真正放不动的就是这一段，压住它，功放才不会提前限幅。诊断「低频压缩」一栏现在会显示真实的段数（ok / 3/6 / fail:…），宽松的 audio server 接受第一段又拒掉其余时不会再被写成 ok。

## 3. limiter 从 6:1 放到 4:1

阈值仍是 -6 dB，attack 5 ms，release 80 ms，比例 6:1 → 4:1。

曲线写进链之前已经有一次「最响段归并到 +6 dB」的预处理，limiter 要做的是抓峰，不是当第二个压缩器用。6:1 意味着每次底鼓或贝斯越过阈值都丢掉相当一部分攻击，听感是低频发平、增益包络跟着持续低音一起抽动。4:1 在超出阈值 12 dB 时仍落在 -3 dBFS，保护没有减少，只是压得更少。

## 4. 测试

新增 RampTest（5 项：0 是静音、1 是原曲线、中间等比、下压段也从平直侧滑入、返回的是新数组）与 MbcShapeTest（6 项：五张表长度一致、cutoff 严格递增、只有低频两段在压、低频段用真实时间常数、release 处处大于 attack、最高段停在 16 kHz）。

全量单测 **68 项全通过**（原 57 项 + 新增 11 项）。

## 已知限制

- **未上真机听音验证**。淡入与压缩器的参数是按信号链推理定的，需要在设备上确认，尤其是「切应用瞬间是否完全消失」与低频是否还抽动。
- 淡入让刚接管播放的会话有约 120 ms 的爬升。整轨从头开始播放时听不出；从中途切进来时理论上是一段很短的渐强，比爆响好得多。
- 签名与 1.4.0 相同（自签 CN=AURORA Observer），与官方原版不同：**覆盖安装前先卸载旧版**。
