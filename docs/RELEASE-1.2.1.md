# AURORA 1.2.1

这一版把「调 EQ」变成了「调音质」，并补上了按应用分配与主题。

## 一、频点重排：解决「浑」

旧的六个频点从 250 Hz 起步，导致想做低频只能抬 250 和 500——而那是 150–600 Hz 的浑浊区，越推越糊。

现在换成 **80 / 200 / 500 / 1.5k / 4k / 10k Hz**：80 Hz 负责真正的低频冲击，200 和 500 让开，1.5k 管人声，4k 和 10k 管清晰度与空气感。

九套预设全部重画，并加了两条硬约束：**200/500 两段不超过 +4 dB**、**相邻频段差不超过 6 dB**。「现场低频」从 `+12/+12/+5/-7/-11/-12` 变成 `+10/+4/-2/+2/+4/+3`——低频更实，但不再糊。

## 二、三种不依赖系统的音质处理

- **多段压缩**：只压 120 Hz 以下，ratio 2、慢释放。EQ 只能改平衡，压不住鼓点的峰值；压缩让低频「实」而不「轰」。
- **音量等响补偿**：音量低于 60% 时按等响曲线补两端（最低频最多 +4 dB）。同一套曲线在小音量下不再发闷。
- **按输出设备调整**：耳机减 3 dB 低频、蓝牙减 2 dB。设备类型取自每条会话的真实输出设备。

## 三、按应用分配

用每条播放会话自带的 UID 识别应用，**不抓前台**——后台播放识别正确，多个应用同时出声也不会串。

指定某个应用后，它播放时始终使用自己的预设，不受全局切换影响。引擎从「每 tick 一条曲线」改为「每会话各算一条」。

## 四、自定义 EQ 与预设管理

- 均衡页新增「创建新 EQ」：进入独立的曲线编辑页，拖完六个频段、写名字保存。
- 保存的曲线出现在官方预设下方，用一条分隔线隔开，标注「我的预设」。
- 支持重命名与删除；删除预设会连带清掉指向它的应用分配。

## 五、界面统一

所有二级页面（设备适配、按应用分配、曲线编辑、新手引导、主题）共用同一个骨架：同一种卡片、同一种按钮、同样的入场动画，退出时统一使用**预测性返回**——侧滑时页面跟着手指缩小加圆角，和主页面一致。

## 六、主题

设置 → 主题 → 管理主题，八套配色：桃粉（默认）、经典蓝、青碧、琥珀、紫罗兰、苔绿、珊瑚、石板。

每套的亮色与暗色是**分别调过的两个色值**，不是同一色值调透明度——暗色版提亮并轻微降饱和，避免在近黑背景上发光刺眼。只改强调色，背景、卡片、文字保持不变。

## 七、修掉的问题

- **刷视频音色跳变**：根因是引擎靠 2 秒轮询发现新会话，新视频开头最多两秒是原厂声。改用 `registerAudioPlaybackCallback` 事件驱动 + 60ms 合并，实测从 2 秒降到 500ms。配合 10 秒宽限期，交替的两个会话都常驻，切换代价为零。
- **Dock 连点回弹**：原实现用互斥锁排队，第二次点击要等第一次动画跑完（表现为「慢一拍、过一会儿自己过来」）；且 `spring` 被打断时带着速度回弹。改为不排队 + `tween`，新点击直接打断旧动画。
- **反馈提交报「网络未连接」**：主域 nginx 缺 `/feedback/` 反代，POST 落到 SPA 兜底返回 405，客户端却把所有失败归因于网络。已补反代，客户端改为区分「服务器拒绝（带状态码）」和「连不上」。
- **频段标签错误**：1.5 kHz 被显示成「1k」。
- **混响区误推**：见第一节。
